### 1. Веб-страница "Главная" (модуль views.py)

**Назначение:** Генерация JSON-ответов для веб-страниц с анализом финансовых данных.

**Основная функция:** `main_page(date_str, transactions_df=None)`

Генерирует JSON-ответ со следующими данными:
- **Приветствие** - в зависимости от времени суток (утро/день/вечер/ночь)
- **Информация по картам** - последние 4 цифры, сумма расходов, кешбэк (1% от трат)
- **Топ-5 транзакций** - по абсолютной сумме платежа за текущий месяц
- **Курсы валют** - получение через API ЦБ РФ (настраиваются в user_settings.json)
- **Цены акций S&P500** - настраиваются в user_settings.json

**Технические особенности:**
- Автоматическое определение начала месяца от указанной даты
- Интеграция с внешними API для получения актуальных курсов валют
- Полное логирование всех операций в `logs/views.log`
- Обработка ошибок с возвратом JSON с описанием проблемы

**Пример использования:**
```python
from src.views import main_page

# Генерация страницы на конкретную дату
result = main_page("2021-12-31 16:00:00")
print(result)

# Вывод (пример JSON):
# {
#   "greeting": "Добрый день",
#   "cards": [
#     {"last_digits": "7197", "total_spent": 1262.00, "cashback": 12.62}
#   ],
#   "top_transactions": [...],
#   "currency_rates": [...],
#   "stock_prices": [...]
# }
```

**Дополнительные функции модуля:**
- `get_greeting(current_time)` - определение приветствия по времени суток
- `get_cards_info()` - анализ расходов по картам
- `get_top_transactions()` - получение топ-N транзакций
- `get_currency_rates()` - получение курсов валют через API
- `get_stock_prices()` - получение цен акций
- `load_user_settings()` - загрузка пользовательских настроек

### 2. Сервис "Простой поиск" (модуль services.py)

**Назначение:** Поиск и анализ транзакций с использованием функционального программирования.

**Основная функция:** `simple_search(transactions, search_string)`

Выполняет поиск транзакций по строке запроса в описании или категории.
- Поиск **без учета регистра**
- Возвращает JSON со всеми найденными транзакциями
- Использует функциональное программирование (filter, map)

**Пример использования:**
```python
from src.services import simple_search
import pandas as pd

# Загрузка данных
df = pd.read_excel("data/operations.xlsx")
transactions = df.to_dict("records")

# Поиск транзакций в Ленте
result = simple_search(transactions, "Лента")
print(result)  # JSON с найденными транзакциями
```

**Дополнительные функции модуля:**

1. **`search_by_phone_numbers(transactions)`**
   - Поиск транзакций, содержащих телефонные номера
   - Использует регулярные выражения для поиска номеров формата +7 XXX XXX-XX-XX
   - Возвращает JSON с транзакциями

2. **`search_transfers_to_individuals(transactions)`**
   - Поиск переводов физическим лицам
   - Категория "Переводы" + имя и первая буква фамилии (например, "Сергей А.")
   - Использует regex для валидации формата имени

3. **`investment_bank(month, transactions, limit)`**
   - Расчет суммы для "Инвесткопилки" через округление
   - Параметры: month ("YYYY-MM"), limit (10, 50 или 100 руб)
   - Округляет траты до ближайшего большего числа, кратного limit
   - Возвращает сумму для откладывания

   ```python
   # Пример: округление до 50 рублей
   # Покупка 112.50 руб → округление до 150 руб → в копилку 37.50 руб
   total = investment_bank("2021-12", transactions, 50)
   print(f"Можно отложить: {total} руб")
   ```

4. **`cashback_categories_analysis(data, year, month)`**
   - Анализ выгодности категорий для повышенного кешбэка
   - Рассчитывает потенциальный дополнительный кешбэк (5% вместо 1%)
   - Возвращает JSON с категориями, отсортированными по выгодности

**Технические особенности:**
- Полное применение функционального программирования (filter, map, lambda)
- Логирование всех операций в `logs/services.log`
- Обработка различных форматов дат
- Поддержка regex для сложного поиска

### 3. Отчет "Траты по категории" (модуль reports.py)

**Назначение:** Генерация отчетов по расходам с автоматическим сохранением в файлы.

**Основная функция:** `spending_by_category(transactions, category, date=None)`

Возвращает траты по заданной категории за последние **три месяца** от указанной даты.

**Параметры:**
- `transactions` - DataFrame с транзакциями из operations.xlsx
- `category` - название категории (например, "Супермаркеты")
- `date` - дата в формате "DD.MM.YYYY" (если None, берется текущая дата)

**Возвращает:** DataFrame с колонками:
- Месяц (формат YYYY-MM)
- Общая сумма трат за месяц
- Количество операций

**Пример использования:**
```python
import pandas as pd
from src.reports import spending_by_category

# Загрузка данных
df = pd.read_excel("data/operations.xlsx")

# Получение отчета по супермаркетам за 3 месяца до 31.12.2021
result = spending_by_category(df, "Супермаркеты", "31.12.2021")
print(result)

# Вывод:
#      Месяц  Общая сумма  Количество операций
# 0  2021-10      2500.00                   15
# 1  2021-11      3200.50                   18
# 2  2021-12      2800.75                   20

# Отчет автоматически сохраняется в reports/report_spending_by_category_*.txt
```

**Дополнительные функции модуля:**

1. **`spending_by_weekday(transactions, date=None)`**
   - Средние траты в каждый день недели за последние 3 месяца
   - Возвращает DataFrame с днями недели и средними суммами
   - Полезно для планирования бюджета по дням недели

2. **`spending_by_workday(transactions, date=None)`**
   - Средние траты в рабочие и выходные дни за последние 3 месяца
   - Сравнение расходов: "Рабочий день" vs "Выходной день"
   - Помогает понять паттерны трат

**Декоратор `@report_to_file(filename=None)`**

Автоматически сохраняет результат функции в файл:
- Без параметра: `reports/report_<имя_функции>_<timestamp>.txt`
- С параметром: `reports/<filename>`

Поддерживает форматы:
- DataFrame → строковое представление таблицы
- dict/list → JSON с отступами
- str → как есть

**Пример использования декоратора:**
```python
from src.reports import report_to_file

@report_to_file(filename="my_custom_report.txt")
def my_analysis_function():
    return {"total": 5000, "count": 25}

result = my_analysis_function()
# Результат сохранен в reports/my_custom_report.txt
```

**Технические особенности:**
- Автоматическое создание директории `reports/` при первом запуске
- Обработка различных форматов данных (DataFrame, dict, list, str)
- Логирование всех операций в `logs/reports.log`
- Группировка данных по месяцам/дням с использованием pandas
- Автоматическое определение рабочих/выходных дней
- Перевод названий дней недели на русский язык

### 4. Файл настроек user_settings.json

Содержит пользовательские настройки для отображения валют и акций на главной странице:

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

**Параметры:**
- `user_currencies` - список кодов валют для отображения курсов (USD, EUR, GBP и т.д.)
- `user_stocks` - список тикеров акций S&P500 для отображения цен

Файл автоматически загружается функцией `load_user_settings()` из модуля `views.py`.
